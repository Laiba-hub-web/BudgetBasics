Your budgeting checklist

Six steps to a budget

  1. Add up income. Allowance, pay and gifts.
  2. List fixed costs. Hostel share, fees, internet.
  3. Estimate variable costs. Food, rides, snacks.
  4. Set a savings target. Start with 20% or whatever you can.
  5. Track daily. Write each spend down.
  6. Review monthly. Adjust what did not work.

Needs vs Wants

A need keeps you healthy, learning and moving. A want is nice to have but can wait. Decide for each item.

Score: 0 / 0

Before you buy: decision guide

  1. Do I need it now? If yes, budget for it first.
  2. Can I wait? If it is not urgent, it can wait for the next wants budget.
  3. Can I afford it? Check your remaining wants money before deciding.
  4. Will this affect my savings goal? Never buy a want from your savings money.

The 50-30-20 Rule

Split your income into 50% needs, 30% wants and 20% savings. It is a starting guideline, and you can adjust it to your life.

Formula: needs = income x 0.50, wants = income x 0.30, savings = income x 0.20. This is an estimate for learning purposes only, not financial advice.
